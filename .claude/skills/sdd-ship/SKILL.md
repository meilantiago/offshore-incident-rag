# /sdd-ship: PR for spec $ARGUMENTS

1. Preconditions:
   - `python scripts/check.py --all` is green;
   - `docs/specs/STATUS.md` shows the spec as `done`;
   - the tree is clean.

   If something fails, go back to `/sdd-verify`.
2. Generate the parts of the PR body **with the scripts**, never by hand:
   - the matrix: `python scripts/traceability.py --md NNN`;
   - the gates: the output of `python scripts/check.py --all` (the `[ok]`/`[FAIL]` lines and the summary);
   - if the spec touched retrieval or generation: the summary of the latest report in `eval/reports/`.
3. Fill `.github/pull_request_template.md` with a 3-line summary, the spec link, the matrix and gates, the discarded findings and remaining debt, and the ADRs.
4. Push the branch (`git push -u origin spec/NNN-slug`; the user confirms the push) and open the PR against `main` with `gh pr create`. If `gh` is not available, leave the title and body ready to paste.
5. Tell the user that the merge is theirs (human gate 2) and what to look at first.

Never merge, never push to `main`, never use `--force`.
