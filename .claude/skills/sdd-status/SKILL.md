# /sdd-status

1. Run `python scripts/status.py` (regenerates `docs/specs/STATUS.md`) and `python scripts/check.py --fast`.
2. Show the table as it comes out and the red gates, if any.
3. For every spec that is not `done` or `superseded`, give the next step:

| State | Next step |
|---|---|
| `draft` without `plan.md` | `/sdd-plan NNN` |
| `draft` without `tasks.md` | `/sdd-tasks NNN` |
| complete `draft` | the user approves with `python scripts/approve.py NNN` |
| `stale` | the user reviews the change and re-approves |
| `approved` / `in-progress` | `/sdd-build NNN` |
| `done` without a merged PR | `/sdd-verify NNN`, then `/sdd-ship NNN` |

4. If nothing is in progress, suggest the next spec from `docs/product/roadmap.md`.
